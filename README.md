# SCAF

面向低照度 RGB-D 视觉里程计的几何与时序可靠性感知描述子增强研究。

本仓库围绕低照度条件下的特征误匹配问题，研究如何结合深度几何信息与时序跟踪可靠性，提高局部描述子的辨别力，并评估精度与计算开销的关系。

## 当前状态

目前已完成 Git 初始化、GitHub 与训练服务器首次同步，并制定[分阶段开发与实验计划清单](docs/DEVELOPMENT_PLAN.md)。算法代码、训练流程及正式实验尚未实现，下一步为阶段 1：工程骨架、运行环境与实验协议。

## 研究内容

### 深度几何可靠性引导的局部描述子增强

以 SuperPoint 为基础特征提取器，利用标定参数和深度反投影获得关键点三维坐标，在帧内局部邻域聚合中引入相对三维几何关系。结合深度有效性与局部连续性衡量几何可靠性；深度缺失或不可靠时，降低几何分支的贡献。

### 时序可靠性引导的学习与匹配

根据前后向光流误差衡量跟踪可靠性，用于描述子学习时的监督加权和推理时的匹配筛选。训练同时保留正负样本区分目标，避免只依靠描述子一致性训练。

光流前后向一致仅表示跟踪可靠，不能单独作为静态点判据。单帧邻域聚合称为帧内局部上下文增强，跨帧信息交互需单独定义。

## 实验边界

- 首阶段聚焦特征增强与固定后端的 RGB-D 视觉里程计验证。
- 直接对比 SuperPoint、SuperPoint + FeatureBooster 与本方法，使用相同的最近邻匹配器和评测设置；另以 SuperPoint + LightGlue 比较完整匹配流程。
- 按完整序列或场景划分训练、验证和测试集，避免相邻帧泄漏；学习方法至少使用三个训练随机种子。
- 合成低照度与真实低照度数据分别报告，不能用人工调暗结果替代真实夜间结论。
- 报告匹配准确性、有效匹配数、ATE/RPE、轨迹覆盖率、跟踪成功率及失败次数。
- 在相同硬件、分辨率和关键点预算下，分别记录提取、增强、光流、匹配和完整前端的耗时，展示精度与延迟的关系。
- 只有完成回环、重定位等完整系统验证后，才扩展为 SLAM 系统结论。
