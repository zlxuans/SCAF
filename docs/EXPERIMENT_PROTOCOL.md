# 实验协议 v1（阶段 1）

此文和 `configs/protocol.yaml` 约定阶段 2/3 的实现口径。当前仅实现基础设施检查，尚无检测器、匹配器或轨迹评测代码；本协议不是实验结果。

## 输入与公平对比

- 同一序列的所有方法使用完全相同的帧、RGB/Depth 关联与退化参数。图像按比例缩小至不超过 640×480，不放大；阶段 2 实现时同步缩放关键点坐标、深度与相机内参。深度采用最近邻采样，保留无效掩码。
- 深度单位统一为米。每个数据集显式指定内参、深度比例、配准方式、参考位姿来源及时间关联容差；不猜测缺失参数。
- SuperPoint 冻结，默认最多 512 个点；效率实验另测 256/1024 点。检测器版本、权重 SHA-256、检测阈值、NMS 参数在阶段 3 基线实现时登记并冻结，所有直接比较共享提取结果。
- 增强前后的描述子采用 L2 归一化，直接比较使用欧氏距离、双向最近邻与距离比阈值 0.8，目标候选不足两个时不通过比值检验。几何和时序模块分别设置开关。LightGlue 使用其完整匹配流程，登记官方配置，不假装共享最近邻匹配器。
- 数据按场景/完整序列分组，训练与验证选择阈值，测试结果不得用于选型。合成低照度与真实低照度单列，训练种子和退化种子独立记录，默认均为 7/13/29。

## 匹配和轨迹

- 匹配正确性基于已知位姿、深度投影和目标深度遮挡检查；重投影阈值 3 像素。报告可评判匹配数、正确匹配数、精确率及未能评判的原因，自身 RANSAC 内点率作为辅助指标。
- 固定 RGB-D PnP 后端：最少 6 个有效对应，RANSAC 阈值 3 像素、100 次迭代、置信度 0.999。具体求解器和最小内点要求在阶段 3 明确并对所有前端固定。
- 保存 SE(3) 位姿和时间戳。失败时中断当前有效轨迹段，不用参考位姿重置估计，不把静止填充当作成功跟踪；报告段长度、最长段、失败次数和覆盖率，不能只展示最优片段。
- ATE 使用同一时间关联后的 SE(3) 刚体对齐，无尺度缩放。RPE 用相对变换计算，间隔为相邻选中帧，分别报告平移米与旋转度；声明选帧步长和实际时间间隔。按段对齐仅作段内指标，不能当作完整轨迹 ATE。
- 训练、评测版本、数据/划分清单、权重校验和、后端阈值进入每次记录。缺真值或标定时不报告无依据的 ATE/RPE。

## 计时和统计

- GPU 计时先同步再起表、结束同步，避免只统计异步提交。预热 10 对，正式计时至少 100 对；短序列不足时标记限制，不通过重复同一帧冒充独立样本。
- 分别记录提取、增强（含邻域构图）、光流、匹配、后端与完整前端计算耗时；含磁盘读取的端到端耗时另列。
- 标注设备、精度、分辨率、关键点预算、线程、预处理/缓存策略和版本。冷启动单列；报告 P50/P95、参数量和峰值显存。
- GPU 与其他任务共享时只能进行功能验证，不能发布性能基准。正式速度测试等独占或稳定空闲条件；同一批对比记录 GPU 初始占用。
- 逐序列结果和失败项完整保留；学习模型报告三个独立训练种子的均值与标准差。预训练基线的重复计时不能称为独立训练。

## 运行记录与恢复

阶段 1 的 `scaf smoke` 输出到唯一目录：`manifest.json`、解析后的 `config.json`、`dependencies.txt`、`events.jsonl`、`checkpoint.pt` 和成功后的 `result.json`。运行失败保留状态与错误；UTC 时间用于机器记录，用户进度日期按 Asia/Shanghai。

`manifest.json` 保存 Git 提交与脏工作区标记、实际源码路径、配置、两个种子、设备清单、命令及依赖版本。阶段 1 的数据、划分、预训练权重字段明确为 null，后续接入真实实验后必须填写对应来源与校验信息。

基础设施恢复仅恢复 CPU 随机状态、已完成步骤和检查结果，要求源代码提交一致且工作区干净、关键配置一致。此检查不包含模型或优化器；完整训练检查点在阶段 6 实现模型、优化器、调度器、随机数、采样器及数据进度恢复。

以后修改协议必须更新版本并说明变更。不得把不同协议的结果混成同一对比。
