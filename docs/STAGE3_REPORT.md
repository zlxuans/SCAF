## 限制和下一步

本阶段验证基线与评测流程，不包含 SCAF 几何/时序模块，不构成本文新方法有效性的证据。真实低照度测试集保持保留；现有训练仅一个短场景、真实低照度仅一个独立场景，数据规模问题仍须在正式训练和测试前补足。开发前缀、合成调暗、单训练种子配置的预训练模型推理均不能代替完整独立测试或多种子训练。

三种方法的精确率只针对可评判的预测匹配，必须同时查看可评判比例、正确匹配数和拒绝原因。当前几何标注仍有 TUM 近似标定、RGB/Depth 时间差及动态物体等局限；RANSAC 内点数不能替代真值评分。参考位姿缺失的帧保留跟踪状态，但不计入需要真值的匹配/轨迹分数。ATE 对有效关联真值位置计算，不代表缺失位置也获得了独立验证。
